### Примерный шаблон базовых ролей.

| Роль                                                          | Права роли                                                                                        | Группы пользователей                                                            |
|---------------------------------------------------------------|---------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------|
| cluster-admin                                                 | Полный доступ ко всем ресурсам кластера.                                                          | Администраторы                                                                  |
| client-admin                                                  | Доступ ко всем ресурсам namespace client                                                          | Dev-ops инженеры, администраторы, тим лиды по работе с клиентами                |
| tenant-admin                                                  | Доступ ко всем ресурсам namespace tenant                                                          | Dev-ops инженеры, администраторы, тим лиды по работе с жильцами                 |
| smart-admin                                                   | Доступ ко всем ресурсам namespace smart                                                           | Dev-ops инженеры, администраторы, тим лиды по работе с интеграциями умного дома |
| client-edit                                                   | Управление ресурсами (развертывания, конфиги), но без доступа к RBAC и секретам, namespace client | Старшие разработчики                                                            |
| tenant-edit                                                   | Управление ресурсами (развертывания, конфиги), но без доступа к RBAC и секретам, namespace tenant | Старшие разработчики                                                            |
| smart-edit                                                    | Управление ресурсами (развертывания, конфиги), но без доступа к RBAC и секретам, namespace smart  | Старшие разработчики                                                            |
| client-view                                                   | Просмотр ресурсов без секретов namespace client                                                   | Аналитики и тестировщики                                                        |
| tenant-view                                                   | Просмотр ресурсов без секретов namespace tenant                                                   | Аналитики и тестировщики                                                        |
| smart-view                                                    | Просмотр ресурсов без секретов namespace smart                                                    | Аналитики и тестировщики                                                        |
| secret-viewer                                                 | Просмотр Secret-ресурсов                                                                          | Специалисты ИБ                                                                  |
| viewer-shared                                                 | Только чтение общих ресурсов (напр. сервисов интеграции или логирования).                         | Все команды                                                                     |
